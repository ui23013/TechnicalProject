# TechnicalProject
All code associated with my technical Project

1. 1d_model_v1: code to numerically solve for the solvent concentration from the 1D non-linear model. Fixed boundary assumption. Implementation verified against a simpler, exact solution.
2. 1d_model_v2: code to numerically solve for the solvent concentration form the 1D non-linear model. Considers moving boundary using a Landau transformation. Implementation verified using conservation of total solute mass integral.
